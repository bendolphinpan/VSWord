## §1 Markdown 元数据命令（人工点击）

| ✓ | 项目 | 操作 | 期望 |
|---|------|------|------|
| [ ] | 打开 Markdown | 打开任意 `.md` | 正常进入编辑器 |
| [ ] | 元数据命令入口 | 命令面板执行 `VSWord: Update Markdown Metadata` | 依次弹出 title / status / tags 三个输入框 |
| [ ] | 默认值回填 | 文档已有 frontmatter 时执行命令 | 三个输入框预填当前 title / status / tags |
| [ ] | 写回正确 | 改 title 后回车走完三步 | frontmatter 中 title 更新，正文不变 |
| [ ] | 保留其他字段 | 文档含 `created` / `cover` / 自定义字段，仅改 title | 这些字段**全部保留**（本次修复重点） |
| [ ] | tags 多值 | tags 输入 `writing, 中文，draft` | frontmatter 写出 `tags: [writing, 中文, draft]` |
| [ ] | 取消 | 任一步按 Esc | 文档无任何改动 |
| [ ] | 非 Markdown 守卫 | 在 `.ts`/`.txt` 上执行命令 | 提示"请在 Markdown 文档使用"，不报错 |
