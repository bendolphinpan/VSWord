## 1. 5 个主题 id 语义

id 白名单来自 `milkdownEditorThemes.ts::VSWORD_MILKDOWN_THEME_IDS`
（`['default', 'github', 'newsprint', 'night', 'solarized-light']`）。JS 镜像位于
`webview/themes.template.js`，仅在 webview 侧做 `themeChanged` 消息 payload 校验，
**不携带 CSS 内容**（CSS blob 由 host 侧的 `getThemesCss()` 生成后直接内联进
webview HTML `<style>`）。

| id | 视觉定位 | 亮/暗 | 设计意图 |
|---|---|---|---|
| `default` | 无覆盖，回退到 `:root` base tokens | 跟随 workbench | **不设置 `data-theme` 属性**——`body[data-theme="…"]` 选择器全落空，token 层只剩 base，跟随 Code OSS 工作台配色。webview initialTheme 落 `'default'` 时也走这条路。 |
| `github` | 白底、蓝调、GitHub sans-serif | light | 技术文档基调；16px 正文、`#0969da` 链接、`#f6f8fa` code 背景，字体栈匹配 GitHub 官方 primer。 |
| `newsprint` | 米黄底、Charter serif、720px 窄栏 | light | 编辑部报刊风；17px/1.7 行距、酒红 `#8f2b2b` 强调色、`--vsword-max-width: 720px` 收窄栏宽，为长篇散文/中文写作打造。 |
| `night` | Typora 招牌暖深灰 `#363636` + 沙金 `#d1a54b` | dark | Typora "Night" 主题的 milkdown 复刻；`color-scheme: dark` 让 workbench 滚动条自动切暗。 |
| `solarized-light` | Ethan Schoonover 米色底 `#fdf6e3` + 灰蓝 `#268bd2` | light | 复古程序员配色；`#eee8d5` code 背景、`#93a1a1` 引用线。 |

**共享 base 层**（`:root`）：字体族（`--vsword-font-serif` / `--vsword-font-sans`）、
最大宽度、字号、行高、标题字体、链接色（默认取 `--vsword-accent`）、引用条、
code / pre 背景、表条纹。**每个非-`default` 主题**通过覆盖对应 `--vsword-*` 变量
换肤，`#milkdown-root .ProseMirror` 及其 6 级 heading、blockquote、code、pre、
table 都以变量消费，主题不必重复写选择器。

**编辑器内容列居中**：`#milkdown-root, #milkdown-source` 的左右 padding 用
`max(24px, calc((100vw - var(--vsword-max-width)) / 2))` 绑定 `--vsword-max-width`，
所以 newsprint 的窄栏、其他主题的 860px 栏宽都是一句变量决定。

## 2. 主题决策路径（`readEffectiveTheme` 伪代码 + ASCII 流程）

**实现锚点**：`milkdownEditorContribution.ts` L470–L487。

```
readEffectiveTheme():
  follow = config.vsword.theme.followWorkbench == true
  if follow:
    kind    = themeService.getColorTheme().type
    isDark  = kind ∈ { DARK, HIGH_CONTRAST_DARK }
    key     = isDark ? config.vsword.theme.dark : config.vsword.theme.light
    raw     = configurationService.getValue(key)
    return isValidTheme(raw) ? raw : (isDark ? 'night' : 'github')
  else:
    stored = storage[vsword.milkdown.lastTheme]        // APPLICATION scope
    return isValidTheme(stored) ? stored : 'default'
```

**Fallback 语义**：`isValidTheme()` 只把 5 个白名单 id 认作合法；任何脏 storage
或脏 config 值都会被回退到 `'default'`（followWorkbench=false 分支）或 `'night'` /
`'github'`（followWorkbench=true 分支）。

**只有一个 storage key**（`VSWORD_MILKDOWN_THEME_STORAGE_KEY = 'vsword.milkdown.lastTheme'`），
scope 是 `StorageScope.APPLICATION`，target 是 `StorageTarget.USER`——主题偏好跨
workspace 生效，跟随用户不跟随项目。

## 3. 四入口关系表（Storage / Config / Command / Broadcast）

| # | 入口 | 位置 | 触发主题变化的信号 | 订阅者 |

| 3 | **Command**：`vsword.selectMarkdownTheme` | `SelectMarkdownThemeAction` (`milkdownEditorThemeRegistrations.ts` L87–L112) | Quick-pick 选中 → 走 (1) 的 storage 写入路径 | 通过 (1) 的订阅者广播 |

**广播出口** `broadcastTheme()`（`contribution.ts` L489–L495）——**唯一** post 端：

```
broadcastTheme():

  isDark = readIsDark()                          // L497–L501
  for input in liveInputs:
    post(input, { type: 'themeChanged', theme, isDark })
```

**其它需要主题的时机**：
- **新 webview 首次装配**：`getMilkdownEditorHtml({ initialTheme: readEffectiveTheme() })`（L267）——把主题 id 塞进初始 HTML `<body data-theme="...">`，webview 一开屏就带对主题，不用等 postMessage。
- **webview 显式请求**：webview `themeRequest` 消息（`entry.template.js`）→ contribution.ts L350–L352 → 单发一条 `themeChanged`。
- **postInit**：contribution.ts L404 首次 init 完成后主动补一条 `themeChanged`，让 webview 侧 NodeView 联动能拿到 `isDark` 初值。

## 4. Webview apply 点 + 3 NodeView `isDark` 联动

**入口**：`entry.template.js` L633–L655（`msg.type === 'themeChanged'` handler）。

```js
if (msg.type === 'themeChanged') {
    const theme = String(msg.theme || 'default');
    if (theme === 'default' || theme === '') {
        document.body.removeAttribute('data-theme');           // 回退 :root
    } else {
        document.body.setAttribute('data-theme', theme);       // CSS 变量层生效
    }
    let isDark;
    if (typeof msg.isDark === 'boolean') {
        isDark = msg.isDark;                                   // host 权威
    } else {
        isDark = theme === 'night';                            // 旧版 host 兜底
    }
    try { broadcastMermaidTheme(isDark); } catch (err) { reportError('mermaid-theme', err); }
    try { broadcastFlowchartTheme(isDark); } catch (err) { reportError('flowchart-theme', err); }
    try { broadcastSequenceTheme(isDark); } catch (err) { reportError('sequence-theme', err); }
    return;
}
```

**三个 NodeView 联动出处**：

| NodeView | 广播函数 | 联动效果 | 引入 commit |

## 6. 最小回归清单（`themeAudit.test.ts`）

| # | 断言 | 意图 |
|---|---|---|
| A1 | `VSWORD_MILKDOWN_THEME_IDS`（TS 源）与 `webview/themes.template.js` 里的白名单 **逐字节相同**（长度 + 每个字符串 `===`） | TS/JS 双源在 T-3.7d.2 引入 `ext:*` 外挂 id 前必须先保持基线一致；任何一方偷偷加/删 id 都直接失败 |

| A3 | `HostThemeChangedMessage.theme` 类型是 `string`（宽签名，为 T-3.7d.2 `ext:*` id 让路）；用 TS type-only import + assign 断言 | 提前锁定协议宽度，T-3.7d.2 落地时不用改协议 |
